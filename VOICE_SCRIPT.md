# Voltnutt TCG voice script

64 lines. Record each one and save it with the exact file name shown, then put the files in `app/src/main/assets/www/voice/`.

You can save as **.mp3**, **.m4a** (most phone voice recorders), .ogg or .wav. Keep each clip short, about 1 to 3 seconds, with no long silence at the start.

## Announcer

| File name | Line | When it plays |
| --- | --- | --- |
| `vo_battle_start` | Bots, roll out! Battle start! | A battle begins |
| `vo_your_turn` | Your turn! | Your turn starts |
| `vo_enemy_turn` | Enemy turn. Brace yourself! | The computer’s turn starts |
| `vo_boss_arrives` | Warning! A factory boss has entered the floor! | A boss card is played |
| `vo_super_effective` | Super effective! | An element advantage hit lands |
| `vo_combo` | Combo! | Your third attack in one turn |
| `vo_low_health` | Warning! Core power low! | Your core drops to 5 health or less |
| `vo_victory` | Victory! | You win |
| `vo_defeat` | Defeat. Rebuild and try again. | You lose |
| `vo_factory_cleared` | Factory cleared! New cards unlocked! | You beat a campaign stop for the first time |
| `sp_overdrive_strike` | Overdrive Strike! | A Friendship or Directorate bot uses its special |
| `sp_flame_burst` | Flame Burst! | A Fire bot uses its special |
| `sp_riptide` | Riptide! | A Water bot uses its special |
| `sp_chain_lightning` | Chain Lightning! | A Storm bot uses its special |
| `sp_deep_freeze` | Deep Freeze! | A Frost bot uses its special |
| `sp_sap_drain` | Sap Drain! | A Nature bot uses its special |
